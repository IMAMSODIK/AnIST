Berdasarkan analisis mendalam terhadap codebase, berikut fitur-fitur yang akan dibangun untuk melengkapi sistem sesuai AGENTS.md:

## Phase 1: Dashboard Enhancement — 3 Missing Charts

**Files to modify:**
- `resources/views/dashboard.blade.php` — Tambah 3 chart baru
- `app/Http/Controllers/DashboardController.php` — Kirim data tambahan ke view

**Detail:**
- **KPI Trend Chart** (Line Chart): Tambah `getOverallKPITrend()` di DashboardService untuk menampilkan tren skor keseluruhan per quarter. Gunakan data yang sudah ada dari `getQuarterlyAchievement()` (sudah ada) — cukup render di view.
- **Upload Activity Chart** (Line/Area Chart): Data sudah tersedia dari `$uploadActivity` yang dikirim controller tapi belum dirender di dashboard. Tambah canvas + Chart.js initialization.
- **Initiative Progress Chart** (Horizontal Bar Chart): Tambah `$initiativeProgress` dari DashboardService (method `getInitiativeProgress()` sudah ada). Tambah canvas + Chart.js initialization.

Dashboard akan direlayout: row 1 = 8 widgets, row 2 = 2 chart (Quarterly Achievement + Perspective Performance), row 3 = 3 chart (KPI Trend + Upload Activity + Initiative Progress), row 4 = Quick Actions + Recent Activity.

## Phase 2: Settings Page

**Files to create:**
- `app/Http/Controllers/SettingsController.php` — Controller untuk halaman settings
- `resources/views/settings/index.blade.php` — View halaman settings
- `app/Http/Requests/UpdateSettingsRequest.php` — Validasi input

**Files to modify:**
- `routes/web.php` — Tambah route settings
- `resources/views/layouts/sidebar.blade.php` — Tambah menu Settings

**Fitur Settings:**
- **Profile**: Edit nama dan email user
- **Password**: Ganti password (old, new, confirm)
- **API Configuration**: Tampilkan status Gemini API Key (masked), input untuk update key
- **System Info**: Tampilkan Laravel version, PHP version, DB connection status

Settings disimpan di tabel `users` (untuk profile) dan `.env` untuk API key. Untuk Gemini API key, gunakan helper `config(['services.gemini.api_key' => $value])` + update `.env` file secara runtime.

## Phase 3: Topbar Enhancement — Search & Notifications

**Files to modify:**
- `resources/views/layouts/topbar.blade.php` — Tambah search bar dan notification bell
- `app/Http/Controllers/DashboardController.php` (atau via View Composer) — Kirim data notifikasi

**Search Feature:**
- Search bar di topbar (Alpine.js dropdown)
- Pencarian global: Measurements, Initiatives, Uploads

**Notification Feature:**

- Tampilkan: AI analysis completed, evidence upload status, KPI alerts

**Files to create:**
- `app/Http/Controllers/SearchController.php`
- `resources/views/partials/notifications.blade.php`
- `app/View/Composers/NotificationComposer.php` (View Composer untuk inject data notifikasi ke semua halaman)
